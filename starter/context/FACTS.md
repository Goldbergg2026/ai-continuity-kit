# Личные факты

Храните только устойчивые факты, которые действительно полезны в разных разговорах.

Для фактов, которые могут измениться, добавляйте `LAST VERIFIED`.

## Пример

```text
CURRENT FACT
Fact: Основная рабочая станция использует Ubuntu 24.04 LTS.
LAST VERIFIED: 2026-08-16
Source: подтверждение пользователя
```

## Если факт изменился

Не стирайте старое значение молча и не держите два значения рядом без пометки. Обновите текущее и перенесите прежнее в историю:

```text
CURRENT FACT
Fact: Основная рабочая станция использует Ubuntu 26.04 LTS.
LAST VERIFIED: 2026-11-02
Source: подтверждение пользователя

HISTORICAL
Fact: Ubuntu 24.04 LTS — до обновления 2026-11-02.
```

Так новая сессия без пересказа переписки видит, какое значение актуально сейчас, а какое было раньше.
