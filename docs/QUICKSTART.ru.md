# Быстрый старт за 5 минут

## 1. Скопируйте starter

Скопируйте содержимое `starter/` в новый **приватный** репозиторий, где будет храниться ваш личный контекст.

## 2. Заполняйте только известное

Отредактируйте:

- `context/PREFERENCES.md` — как с вами общаться;
- `context/FACTS.md` — несколько действительно полезных устойчивых фактов;
- `context/MEMORY.md` — повторно полезный опыт, когда он реально появился.

Неизвестное оставляйте неизвестным. Не создавайте биографическое досье только потому, что есть место для текста.

## 3. Используйте START.md как точку входа

Если ваша версия ChatGPT/Codex умеет читать репозиторий — начинайте с `START.md`.

Если автоматического доступа нет, передавайте только относящиеся к задаче файлы, а не весь репозиторий.

## 4. Проект — только когда он нужен

Скопируйте `projects/example/` и переименуйте папку.

- `STATE.md` — где мы сейчас;
- `FACTS.md` — проверенные повторно нужные факты;
- `MEMORY.md` — опыт и ловушки.

## 5. Замыкайте цикл

После существенной работы:

1. проверить результат;
2. обновить правильный файл-владелец;
3. сохранить только полезную дельту;
4. сделать Git commit.
