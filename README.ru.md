## Зачем это нужно

ИИ может помнить полезные вещи, но **память — не то же самое, что проверенный текущий факт**.

Предпочтение пользователя может быть устойчивым. IP сервера — измениться. Решение проекта — быть отменено более поздним решением. Успешный тест месяц назад не доказывает, что система исправна сегодня.

AI Continuity Kit даёт человеку и его ИИ небольшой общий каркас, который не позволяет смешивать эти вещи.

```text
СООБЩЕНИЕ
  ↓
НАЙТИ НУЖНЫЙ КОНТЕКСТ
  ↓
ПРОВЕРИТЬ, ЧТО АКТУАЛЬНО
  ↓
ВЫПОЛНИТЬ РАБОТУ
  ↓
ПРОВЕРИТЬ РЕЗУЛЬТАТ
  ↓
СОХРАНИТЬ ТОЛЬКО ПОЛЕЗНОЕ ИЗМЕНЕНИЕ
```

## Шесть основных принципов

1. **Память не является истиной.** Опыт помогает, но изменяемые факты требуют проверки свежести.
2. **Один факт — один владелец.** Не создавать несколько независимых файлов с «текущей правдой» об одном и том же.
3. **Загружать только нужное.** Не тащить все проекты, логи и старые разговоры в каждый запрос.
4. **Сохранять дельту, а не стенограмму.** Решения, подтверждённое состояние, препятствия и полезные уроки — да; разговорный шум — нет.
5. **Обычный язык важнее внутренней структуры.** Человеку не нужно знать, в каком файле лежит ответ.
6. **Технический доступ не равен разрешению.** Широкие права Codex не означают разрешение на любое действие.

## Уровни

| Уровень | Для чего |
|---|---|
| **Lite** | Повседневное общение и персонализация |
| **Standard** | Личные и рабочие проекты с продолжением |
| **Advanced** | Codex, агенты, права, риски, восстановление и CI |

Начинать следует с Lite. Усложнять систему — только когда появилась реальная необходимость.

## Быстрый старт

Готовый шаблон лежит в [`starter/`](starter/).

1. Скопируйте его в **приватный** Git-репозиторий для своих данных.
2. Аккуратно заполните `context/PREFERENCES.md` и `context/FACTS.md`.
3. Укажите ChatGPT/Codex начинать с `START.md`.
4. Создавайте отдельный проект только тогда, когда у работы появилось устойчивое состояние, которое нужно продолжать.
5. Фиксируйте значимые изменения через Git.

Подробнее: [быстрый старт за 5 минут](docs/QUICKSTART.ru.md).

> **Конфиденциальность:** это публичный шаблон. Реальный личный контекст обычно должен храниться в приватном репозитории. Никогда не помещайте в Git пароли, токены, приватные ключи, cookies и конфигурации с секретами.

## Это не замена встроенной памяти

ChatGPT Memory может быть удобен для адаптивной персонализации. Этот проект решает другую задачу: **явный, проверяемый, версионируемый слой продолжения работы**.

## Статус

**v0.1 preview.** Ядро и starter-шаблон готовы для использования и дальнейшей проверки на реальных сценариях.

Проект независимый и не аффилирован с OpenAI. Названия ChatGPT и Codex используются только для описания совместимых сценариев работы.
